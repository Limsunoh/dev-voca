# 리뷰 체크리스트

이 저장소에서 실제로 밟은 함정 가운데 **diff 만 보고 알아챌 수 있는 것**을 모았다.
`static-verifier` 가 diff 를 읽은 뒤 이 파일을 열어, 굵은 글씨(계기)가 diff 에
해당하는 항목만 확인한다. 보통 몇 개다. 전부 훑을 필요는 없다.

`dynamic-tester` 는 테스트를 쓰기 전에 "테스트" 절을 읽는다.

## 항목을 넣고 빼는 기준

- **넣는다**: 한 번 이상 실제로 밟았고, diff 에 계기가 보인다(어떤 코드·클래스·칸이
  새로 생기거나 바뀌었는지로 알아볼 수 있다).
- **넣지 않는다**: 화면을 열어 봐야만 아는 것, QA 하는 방법, 세션 운영 요령.
  그런 것은 `.claude/CODE_INSIGHTS.md`(로컬 노트)나 `.claude/skills/devvoca-design/SKILL.md` 에 둔다.
- **뺀다**: 계기가 된 코드가 사라졌거나, 테스트가 그 함정을 자동으로 막게 됐을 때.
  이 파일은 커질수록 안 읽힌다.

형식: **계기** - 확인할 것과 이유. *(언제 밟았나)*

---

## 공통

- **리뷰 지적을 고친 수정, 또는 가드를 한 자리에 추가** - 같은 파일에 같은 꼴이 또
  있는지 grep 하고, 형제 디렉터리에 짝 파일(`error.tsx` 등)이 있는지 `ls` 한다. 검증
  3·4라운드가 전부 이것이었다. *(PR #37, #40)*
- **블록 주석 안에 `*/` 가 들어가는 경로 표기(`learn/*/[id]` 등)** - 주석이 그 자리에서
  끝나 나머지가 코드로 읽힌다. tsc 가 원인과 무관한 오류를 수십 건 낸다. *(2026-09-15)*
- **소스에 `\uXXXX` 같은 이스케이프나 보이지 않는 글자** - 도구가 이스케이프를 풀어
  실제 글자로 저장했을 수 있다. 그 줄을 `ascii()` 로 찍어 `\u` 로 나오는지 본다.
  *(2026-11-09, #174 두 번)*

## 백엔드 - 모델·마이그레이션

- **`AddField` 로 기존 표에 `unique=True` 칸 추가** - null 로 추가, 행마다 값 넣기,
  unique 로 바꾸기의 마이그레이션 셋으로 나눴나. callable 기본값은 한 번만 평가돼
  기존 행이 모두 같은 값이 된다. 빈 테스트 DB 에서는 늘 통과한다. *(2026-08-02)*
- **데이터를 옮기는 `RunPython`, 되돌리기가 `noop`** - 되돌렸다 다시 적용하면 같은
  행을 또 넣어 unique 에 걸리고 migrate 가 실패해 서버가 안 뜬다. `WHERE NOT EXISTS`
  같은 중복 방지가 있나. *(#190)*
- **새 마이그레이션 전반** - 배포 중에 옛 코드가 요청을 받는 동안 돈다. NOT NULL 열은
  `db_default` 가 있나. 지우기·이름 바꾸기·제약 추가는 사용자에게 먼저 물었나.
  *(#175, DEPLOY.md "배포 확인")*
- **모델이 아닌 DB 객체(캐시 테이블, 확장, 손으로 만든 인덱스)** - 마이그레이션에
  들어 있나. 테스트 러너가 `createcachetable` 을 대신 해 줘서 테스트로는 안 잡힌다.
  *(2026-08-13, `throttle_cache` 누락으로 인증 API 전부 500)*
- **`search_fields` 를 바꿈** - pg_trgm 인덱스는 `vocab/migrations/0014_search_trgm.py`
  에 손으로 쓴 SQL 로 있다. 0014 를 고치지 말고 `<표>_<칸>_trgm` 이름으로 새
  마이그레이션을 만들었나. *(#193)*
- **판정값을 `@property` 로 만듦** - `filter()`, admin `list_filter`, `order_by()` 에
  못 쓴다. 목록 필터가 필요해지는 순간 `FieldError`. *(2026-08-02)*

## 백엔드 - 조회·응답

- **사용자에게 나가는 응답을 dict 로 손으로 조립** - 검수 게이트(`.visible()`,
  `visible_reading()`)를 거쳤나. 미검수 발음이 이 길로 그대로 나갔다. *(2026-09-11)*
- **상태 필터를 `exclude(...)` 로 씀** - 상태가 셋으로 늘면 반려까지 미검수로 잡힌다.
  `filter(상태=값)` 양 조건으로. *(2026-08-02)*
- **`getattr(obj, "칸", 기본값)`** - 칸 이름 오타가 예외 없이 빈 값이 된다. 빈 값이
  정상 경로에서도 쓰이면 실패가 정상처럼 보인다. *(2026-09-11)*
- **삭제·필터 기준으로 사람이 칠 만한 글자(`source="직접 작성"` 등)** - 다른 데이터와
  겹쳐 남의 행을 지운다. `seed_phrases` 같은 기계 이름으로. *(2026-09-11)*
- **시드 명령에서 항목을 지움** - 시드는 추가·갱신만 한다. DB 에 남은 행을 배포 뒤 지울
  계획이 PR 에 있나. *(2026-08-10)*
- **`query_params.get(...)` 을 직접 꺼내 쿼리에 씀** - DRF 필터 검증을 안 거친다. NUL
  바이트 하나로 Postgres 가 500 을 낸다(`?shuffle=%00`). *(2026-09-16)*
- **같은 쿼리 값을 프론트와 백엔드가 각자 판정** - 기준이 같나(`.strip()` 대 truthy).
  어긋나면 화면과 주소가 다른 상태를 가리킨다. *(2026-09-16)*
- **글자 칸으로 사용자에게 보이는 정렬(`order_by("term")`)** - `Lower("term")` 로
  정렬하고 원래 칸으로 동점을 끊었나. DB 이미지에 따라 기본 정렬이 다르다
  (예전 로컬 alpine Postgres 는 바이트 순이라 운영과 순서가 달랐다). *(2026-09-26)*
- **쪽 나누기 목록의 정렬이 유일한 칸으로 안 끝남** - 끝에 pk 를 붙였나. 거꾸로 읽는
  쪽(`TailReversingPaginator`)에서 항목이 겹치거나 빠진다. *(#199)*
- **근사값을 정렬 키로 씀** - 목록과 내 등수가 같은 근사를 쓰면 정합성 테스트는 늘
  통과한다. 규칙과 맞는지 보는 테스트(한 사용자가 여러 행인 픽스처)가 있나. *(2026-08-16)*
- **새 `order_by("?")`, 또는 `IN (서브쿼리) OR IN (서브쿼리)`** - 콘텐츠가 수십만이면
  절벽처럼 느려진다. 무작위는 `vocab/sampling.py` 의 `pick_random`, 서브쿼리 OR 는
  `EXISTS` 로. *(#197, #200)*
- **`pick_random` 을 새로 부름** - 조건이 표의 1% 아래면 오히려 느리다. 측정했나.
  `random_key` 를 손으로 넣는 코드는 뽑기를 쏠리게 한다. *(#200)*
- **`RoundStep` 을 쓰는 기능 추가** - 토큰 수명이 10분보다 길면 청소가 살아 있는 토큰을
  지운다. `session.LONG_ROUND_PREFIX` 를 붙였나. *(2026-09-27)*

## 백엔드 - 설정·운영

- **`settings.py` 에 `raise` 추가** - CI 는 DEBUG 를 끄고 `manage.py check` 를 먼저
  돌린다. CI 가 값을 넣어 줄 수 없는 외부 계정이면 그 단계가 먼저 죽는다. 쓰는
  시점에 막는다. *(2026-09-10)*
- **로깅 처리기나 모듈 전역에서 네트워크 호출·잠금** - gunicorn 이 스레드 방식이라
  처리기 잠금 안의 메일 한 통 동안 다른 요청이 기다린다. *(#175)*
- **비밀 값을 담는 모델을 관리자 화면에 올림** - 주소 검색어(`?key__startswith=`)로
  한 글자씩 맞힐 수 있다. `lookup_allowed` 를 막았나. *(#190)*
- **날짜로 켜는 기능(날짜 상수와 비교)** - 기존 테스트가 그 날 아침 저절로 빨개지지
  않게 날짜를 고정했나. 지울 날짜를 주석에 적었나. *(#174)*

- **`ai_pipeline` 을 부르는 테스트** - 가짜 클라이언트를 넣었나. 개발기 `.env` 의 키로
  실제 과금이 난다. CI 는 키가 비어 있어 거기선 안 보인다. *(2026-08-02)*
- **방어 코드와 그 테스트를 함께 추가** - "작동한다" 만 보이고 "뚫리지 않는다" 는 안
  보는 테스트가 아닌가. 결과만 비교해 새 경로를 실제로 탔는지 모르는 테스트도 같다.

- **클래스 개수로 요소를 세는 테스트(`rounded-full` 개수 등)** - 모양을 바꾸면 조용히
  무력화된다. 모양과 무관한 치수로 센다. *(#177)*

## 프론트 - 동작

- **타이머·`setTimeout`·`await` 뒤에서 state 를 읽음** - 그 렌더 시점의 옛 값이다. ref 로
  읽나(`QuizBoard` 의 `loadingRef`, `RoundBoard` 의 `tokenRef`). 90초를 다 푼 사람이
  점수를 잃었다. *(2026-08-20)*
- **`<details open={계산식}>`, `<dialog open>`** - 값이 바뀌는 순간 사용자가 연 것을
  닫는다. 상수로 둔다. *(2026-09-06)*
- **`<form action={서버 액션}>` 에 라디오·체크박스, 또는 실패해도 남겨야 할 칸** - 액션이
  끝나면 폼을 reset 한다. 라디오 값은 hidden 칸으로 보내나. *(2026-09-26)*
- **서버 액션 호출을 `try/catch` 로 감쌈** - redirect 도 오류로 와서 실패로 처리된다.
  catch 첫 줄에 `unstable_rethrow(error)`. *(#198)*
- **로그인 없이도 되는 요청에 토큰을 실음** - `withTokenOrGuest` 를 쓰나. RSC 에서
  `getToken()` 을 `try` 안에 두면 Next 의 오류를 삼킨다. *(2026-09-27)*
- **서버 응답으로 useState 초깃값을 정하는 화면** - 뒤로 가기로 돌아오면 옛 응답으로
  그려진다. `RefreshOnBack` 이나 `TabBar` 의 `FRESH_ON_RETURN` 이 필요한가. *(2026-11-09, T11)*
- **떠나면 잃는 화면(한 판, 저장 안 한 폼)** - 폰의 뒤로 가기는 `beforeunload` 가 안
  뜬다. `ExitGuard` 의 Navigation API 리스너를 쓰나. *(2026-11-12)*
- **그림 파일 import** - CI 는 `next-env.d.ts` 없이 `tsc` 를 먼저 돌린다.
  `frontend/src/image-types.d.ts` 가 덮나. `mv next-env.d.ts /tmp && npx tsc --noEmit`
  으로 흉내 낸다. *(2026-11-10)*
- **음성 인식·마이크·`speechSynthesis`** - `lang = "en-US"` 를 줬나, 이벤트가 안 오는
  구간에 자체 타임아웃이 있나, `abort()` 는 `onerror` 없이 끝나는 것을 받나, 영어 음성이
  0개일 때 무엇을 보이나. *(2026-09-11)*
- **`day % count` 같은 순환 인덱스로 "내일" 을 약속** - 개수가 1 바뀌면 수십 칸 튄다.
  *(2026-09-26)*
- **잘리는 높이를 `window.innerHeight` 로 계산** - iOS 는 주소창이 펴진 높이를 준다.
  틀렸을 때 사용자가 못 되돌리는 자리면 `visualViewport` + `offsetTop`. *(2026-09-17)*

## 프론트 - 화면·CSS

- **`fixed bottom-0` 오버레이** - `lib/routes.ts` 의 `immersiveRoutes` 밖 화면에서 쓰면
  탭바를 덮는다. *(2026-09-11)*
- **`pointer-events-none` 으로 화면을 가리는 층** - 가린 채로 아래 버튼이 눌린다. 읽을 수
  없는 상태에서 답을 고르게 된다. *(2026-09-11)*
- **`animation-fill-mode: both`/`forwards`** - 마지막 키프레임이 보이는 상태면 화면에
  영구히 남는다. 지우는 장치가 있나. 두 번 연속으로 봐야 드러난다. *(2026-09-11, 세 번)*
- **반복 애니메이션으로만 상태를 알림** - 감소 모션에서는 사실상 안 보인다. 글자나 정적
  표시가 같이 있나. *(2026-09-10)*
- **긴 문자열(URL, 에러 원문)이 들어가는 자리에 `break-words`** - min-content 폭이 안
  줄어 폰에서 가로 스크롤이 생긴다. `wrap-anywhere` 와 flex 항목의 `min-w-0`.
  *(2026-08-15)*
- **`<wbr>` 을 손으로 넣음** - 빈칸과 같은 줄바꿈 후보라 짧은 덩어리도 쪼갠다. 21자 넘는
  덩어리에만(`lib/wrap-points.tsx`). *(2026-09-27)*
- **좁은 칸의 한글 고정 라벨에 `text-balance`** - `keep-all` 이라 안 먹는다.
  `[word-break:normal]` 을 같이 단다. `break-normal` 은 안전망까지 꺼서 쓰지 않는다.
  *(2026-11-12)*
- **부모를 `flex flex-col` 로 바꿈** - 자식의 `inline-flex` 가 블록이 되어 폭을 다 먹는다.
  *(2026-09-15)*
- **같은 속성의 Tailwind 클래스 둘이 한 요소에(`whitespace-normal` 과 `whitespace-nowrap`,
  `rounded-full` 과 `rounded-[..]`)** - 적은 순서가 아니라 생성된 CSS 순서로 이긴다. 공통
  묶음에서 그 속성을 빼야 한다(`MetaBadge` 의 `CHIP_BASE`). *(#177)*
- **글자색·바탕색 토큰 변경** - 그 토큰이 얹히는 바탕을 전부 세어 가장 어두운 바탕
  기준으로 대비를 계산했나. 포커스 링 대비도. 주석의 대비 수치는 믿지 않는다.
  *(2026-09-10, #141)*
